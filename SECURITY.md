# Security policy

## Supported versions

Security fixes are made against the current supported contents only.

## Reporting a vulnerability

Do not publish potential vulnerabilities in issue trackers or include private source media, local paths, credentials, or access tokens in reports. Send the maintainer a minimal reproduction, affected file/version, impact, and any safe mitigation. The maintainer should acknowledge the report and coordinate a fix before public disclosure.

This project processes untrusted local media and metadata. Treat generated Markdown and OCR text as untrusted until reviewed.
